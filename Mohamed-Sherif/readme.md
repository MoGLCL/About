# 📖 About

This project is a modern personal **About Me page** designed with a futuristic dark-themed UI.

The page showcases personal information, skills, projects, and experience in an attractive and responsive layout using only **HTML, CSS, and Vanilla JavaScript**.

---

# 🚀 Features

- ✨ Modern Dark UI Design
- 🎨 Smooth Animations
- 🖼️ Animated Profile Image
- 📱 Fully Responsive Layout
- ⚡ Interactive Experience Section
- 💻 Skills Showcase
- 🚀 Projects Highlight
- 🔥 Hover Effects & Transitions
- 🎯 Clean and Organized Code
