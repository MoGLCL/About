## 📖 About

This project is a modern personal portfolio hero section designed with a clean and elegant UI.

It includes smooth animations, interactive elements, dark/light mode, and a fully responsive layout using only **HTML**, **CSS**, and **Vanilla JavaScript**.

---

## 🚀 Features

- ✨ Modern UI Design
- 🎨 Dark & Light Mode
- ⌨️ Typing Animation
- 🖱️ 3D Hover Effects
- 🌊 Smooth Scroll Reveal
- 💎 Glassmorphism Design
- 📱 Fully Responsive
- ⚡ Fast Performance
- 🎯 Clean & Organized Code

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts
- SVG Icons
